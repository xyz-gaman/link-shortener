# ShortURL - Ad-Free URL Shortener

A simple, clean URL shortener with no ads or tracking.

## Quick Start

### Local
```bash
npm install
npm start
```
Open http://localhost:3000

### Deploy to Vercel (Free)

1. Go to https://vercel.com
2. Click "New Project"
3. Import this GitHub repo
4. Click "Deploy"
5. Get your live URL

### Deploy to Replit (Free)

1. Go to https://replit.com
2. Click "Import from GitHub"
3. Paste: `https://github.com/xyz-gaman/link-shortener`
4. Click "Run"
5. Open the generated link

## Features

- ✅ No ads
- ✅ No tracking
- ✅ Works with any URL
- ✅ Clean interface
- ✅ Instant short links

## How it works

1. Paste your long URL
2. Click "Shorten"
3. Get a short link
4. Share it!
